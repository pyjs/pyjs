# PyJS 0.5.0

PyJS 0.5.0 expands Python application development across the browser, Node.js,
desktop, JVM, Android and native LLVM targets. It also improves compiler
diagnostics, performance and the tools used to test those applications.

## Highlights

- Native LLVM compilation supports executable programs and shared libraries,
  managed memory, common Python collections, exceptions, generators and async
  functions within its supported typed subset. Native execution is tested on
  Linux, macOS and Windows, on both x64 and arm64.
- JVM and Android support includes broader collection and string semantics,
  exceptions and context managers, typed model JSON, SQLite bindings, native
  calendar APIs, and expanded Android UI and lifecycle support.
- JavaScript gains native typed Promise bindings, IndexedDB helpers, improved
  callback handling and evaluation order, and more precise diagnostics for
  unsupported operations. TypedDict and JSONObject literal-field augmented
  assignments preserve static field lookup; unsupported list/set mutation
  forms now fail explicitly instead of losing aliases.
- Browser UI and testing improvements cover Markdown, diagrams, scrolling,
  focus, hydration, managed-browser execution and Android Chrome automation.
  The third-party integrations include typed xterm.js bindings.
- The performance lab compares shared workloads with CPython and handwritten
  JavaScript, Java and Rust. Compiler and runtime improvements span analysis,
  loops, collections, strings and JSON decoding.
- Toolchain discovery and provisioning use sdkmgr. Python packages and the
  standalone npm CLI are built and installation-tested across supported hosts.

See [the changelog][changelog] for detailed changes and compatibility
boundaries. Backend support is not identical: this release does not promise
arbitrary CPython compatibility or every Python feature on every target.

## Install

Python 3.14 or newer:

```sh
python -m pip install "pyjs==0.5.0"
python -m pip install "pyjs[examples,extras]==0.5.0"
```

The standalone npm CLI bundles Python and does not need a separate Python
installation:

```sh
npm install --global @pyjsdev/cli@0.5.0
pyjs --version
```

The npm runtime packages support Linux x64/arm64 with glibc, macOS x64/arm64,
and Windows x64. Linux musl and Windows arm64 npm packages are not included.
Target-specific SDKs and build tools may still be required.

## Upgrade notes

- Keep `pyjs`, `pyjs-examples` and `pyjs-extras` on the same release version.
- Unsupported constructs may now produce earlier, source-located diagnostics
  instead of generating incorrect code. For list/set record fields, use
  mutation methods when aliases must observe the change, or ordinary assignment
  when replacing the field is intended.
- JavaScript custom in-place methods such as `__iadd__` still have a known
  dispatch limitation; this release does not add that protocol support.
- Some browser APIs require recent browser versions. In particular,
  `Promise.withResolvers` is required by the IndexedDB transaction helper.

Release assets contain the three Python wheels and source archives, the npm
launcher and five runtime archives, and a SHA-256 manifest. The npm runtime
archives contain the compiler and embedded Python, not an application bundle.
