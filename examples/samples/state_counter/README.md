# Reactive counter

This focused PyJS sample demonstrates a state field, an effect, browser
events, server rendering, and tests in a complete runnable project.

## Run

```bash
python -m pyjs_examples.samples.state_counter
```

Open <http://127.0.0.1:8000/>.

## Test

```bash
python -m pytest -q
python -m pytest -q --pyjs-target=web
```
